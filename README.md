# CC-APPSDEV22-Prelim-Week3-ULBINARIO

## Week 3 Laboratory — Data Manipulation, Collections & LINQ

This C# console application demonstrates working with collections, validation, LINQ queries, file I/O, and exception handling.

### Features
- Product validation and filtering
- Dictionary lookup
- LINQ: filtering, ordering, grouping, aggregation
- JSON save / load
- Text report generation
- Exception handling demo

### Modifications Applied
1. **Two new valid products**: Monitor (SKU006), Bread (SKU007)
2. **One invalid product**: SKU008 — empty name, negative price
3. **New LINQ query**: Show products with stock greater than 10
